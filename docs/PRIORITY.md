# 重要信息是怎么排出来的（给使用者的说明）

> 你可以在应用里直接读这一页：**「今日」页 → 重要信息卡片**，或打开 `/docs/PRIORITY.md`。

---

## 它在做什么

一句话：**按你的"未来规划"给刚收进来的信息排先后，并且告诉你为什么。**

它和"信息筛选"是两件事：

| | 回答的问题 | 结果 |
| --- | --- | --- |
| 信息筛选（`lib/relevance.mjs`） | 这条**跟我有关**吗？ | 推给你 / 待确认 / 建议忽略 |
| **重要信息**（`lib/priority.mjs`） | 这条**对我多重要、有多急**？ | 重要 / 一般 / 低 + 0~100 分 + 理由 |

---

## "你的未来规划"由四样东西拼成

1. **你自己写的规划**（在「今日」页那张卡里填，一行一条）；
2. **里程碑**（考试 / 截止 / 目标 + 日期）；
3. **校历与考试**（学期起止、考试周）；
4. **未来 14 天的任务与日程**。

系统从这四样里抽出关键词（规划词、课程代码、考试名、事件名……），拿新信息去比对。

---

## 加减分表（可以照着调你的用法）

| 因素 | 加减分 |
| --- | --- |
| 明天内到期 / 3 天内 / 一周内 / 14 天内 | +35 / +25 / +15 / +8 |
| 没做完的任务已经逾期 | +18 |
| 纯提醒已过期几天 / 超过 3 天 | −8 / −12 |
| 命中未来规划关键词（标题全额、正文 40%） | 最多 +30 |
| 标题里有"提交 / 报名 / 确认 / 截止" | +12 |
| 标题里写了紧急 / 务必 / 尽快 | +8 |
| 标题和课程作业 / 考试相关 | +6 |
| 来源是交大邮箱 / Canvas | +10（通用邮箱 +5） |
| 还没处理过的外部条目 | +5 |
| 你以前保留过 / 忽略过 3 次以上 | +8 / −25 |
| 相关度裁决是"建议忽略" | −20 |

中性起点 **30** 分；**≥70 重要**、**≥45 一般**。

---

## 建议（两档）

- **规则版**：不联网、随时可用，能给出"最急的一件 / 规划相关的一条 / 考试临近 / 撞车日"这几类提醒；
- **agent 版**：点「让 agent 分析」，用你自己配的模型基于**同一份数据**写 2~3 条可执行建议。
  - **高峰时段（工作日 9–12 / 14–18）不会调用模型**；
  - 模型没配好或调用失败时，会自动回落到规则版，并用人话说明原因；
  - 如果你的模型是"**别的模型跑在 Codex 壳子里**"（例如 `~/.codex/config.toml` 里写着 `model_provider = "deepseek"`，
    指向本机一个中转地址），到「数据源 → Agent 接入」选 **「沿用本机 Codex 的模型配置」**即可 ——
    平台会复用那份地址与令牌（**令牌只在调用那一刻读，不复制进平台**），不用再粘一次 Key。

---

## 它**不会**做的事

- 不会**自己**把你的信息推成通知 —— 但你现在可以亲手打开「⚡ 自动推送」（见下一节）；默认仍是关闭；
- 不会改动或删除你的任务 / 日程 / 通知；
- 除「让 agent 分析」外不联网。

---

## ⚡ 自动推送（默认关，由你打开）

前几节讲的都是"**你去看**"。如果你希望**重要的信息自己来找你**，在「今日 → 重要信息」卡片底部打开「自动推送」：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 启用 | **关** | 不打开就什么都不会发（这是刻意的：打扰策略由你决定） |
| 进通知 | 勾 | 达到阈值的信息变成一条通知（会真的弹一次提醒） |
| 推手机 | 不勾 | 额外推到手机（走 Bark；要先在「手机与办公本」里配好） |
| 阈值 | 70 | "重要"档的下限（45~100，可调） |
| 每次最多 | 3 | 一次最多推几条，避免刷屏 |

四条防刷屏规则：**同一件事 24 小时内不重复**（按"来源+标题"记）、**一次最多几条**、
**太远的（默认 >7 天）不推**、**已经过期的不推**。

不想开也可以先点「现在跑一次（预览）」看看"按当前设置会推哪几条"—— **预览不需要打开开关**。

> 推出去的那条会标记成来源 `priority`，**不会再被算成"新信息"**（否则会自己喂自己）。
