# 模块：连接向导

第三个可插拔模块（`kind: gadget`，挂在「数据源」页最上面）。

它解决的是"**填个 Token 就能用**"里最容易卡住的那一步：**填完不知道对不对**。

三步：

1. **选数据源**（下拉，来自 `/api/state.connectors.meta`）；
2. **填字段**（自动生成表单，带占位提示；已保存过的字段会回填掩码，原样带回即沿用旧值）；
3. **测试连接**（`POST /api/connectors/:source/test`，真拉一次少量数据）→
   ✓ 直接告诉你"能看到 N 条"，✗ 把人话原因说出来（例如"邮箱通常不能用网页密码，要用应用专用密码"）。

测试通过后一键**保存并导入**。

## 为什么做成模块

它读写的都是连接器配置（`data.reads/writes` 已声明），不碰别的表；
按钮、表单、错误提示全在模块里，主程序一行没改 —— 这就是模块系统的意义。
