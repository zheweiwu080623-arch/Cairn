# 能力搭建（flow-builder）

用**能力**拼出一个新功能的一页（M3）。左边是能力素材栏，点一下就加一个节点；
相邻节点之间自动连一条线；可以拖动换顺序；「试跑」只演练（真数据、零副作用）；
满意了「存成新功能」就会在 `modules/<id>/` 下写出 `module.json` + `flow.json` + `README.md`。

存出来的功能**没有 run.js** —— 它就是一张能力图，由 `lib/flow.mjs` 执行。

页面只调四个接口：`GET /api/capabilities`、`GET /api/flows`、
`POST /api/flows/dry-run`（**永远只演练**）、`POST /api/flows/save`。

## 2026-10-02 起（v0.6.0）：三条路，从"用它拼"到"写一段代码"

| 想干的事 | 怎么做 | 要写代码吗 |
| --- | --- | --- |
| 做一件新事情 | 点能力 → 连线 → 写条件 → 试跑 → **存成新功能** | 不用 |
| 要一条新的原子动作 | 同上，点 **存成新能力**（写进 `<数据目录>/capabilities/<id>.json`） | 不用 |
| 要真的写点逻辑 | 「🛠 开发 · 能力」里写单文件，或**打开能力目录**用你自己的编辑器改 | 要（但不必在浏览器里写） |

* **条件（"如果…就…"）**：每个节点下面那个虚线框 —— `$pick.count > 0`、`$get.ok`、
  或完整 JSON `{"ref":"$a.b","op":"eq","value":"x"}`。条件不成立 = **安静跳过**（不是失败），
  而且"上游没跑 ⇒ 下游也不跑"会自动传下去；
* **同一张图，存成功能或存成能力**：存成能力之后它当场进素材栏，可以像自带能力一样被拼进别的图；
* **打开能力目录 / 重新扫描**：能力就是数据目录下的普通文件，平台每次读取都会重扫 ——
  用 VS Code / Codex 改完回来点一下即可，**不用重启服务**。

详见 `docs/WRITING_A_CAPABILITY.md`。
