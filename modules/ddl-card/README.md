# DDL 提醒（ddl-card）

挂在「任务」页的卡片（**不占今日页**）。对应你最早提的那句："ddl 的时候提醒和倒计时其实也可以加上……
不然有可能就真的忘了。"

引擎（`lib/ddl.mjs`：档位 / 倒计时文案 / 去重键）早就写好了，这张卡把它**接上**：

| 它做什么 | 说明 |
| --- | --- |
| 五档提醒 | 默认 **剩 7 天 / 3 天 / 1 天 / 3 小时 / 30 分钟**，每档只响一次（跨重启有效） |
| 不打扰做完的事 | `status=done` 的任务不再提醒；没有截止时间的不管 |
| 睡醒也能补上 | 档位落在"最近 15 分钟内"就算刚该提醒（电脑休眠/重启后不会漏掉） |
| 手机 | 默认**不推**；勾了才推，而且只发一句话（≤60 字，Bark 显示不了长文本） |

2026-09-28（P2「就地设置」推广）：**档位与"推手机"搬进了页头那颗 ⚙ 功能设置** ——
卡片上只留"开关 / 保存 / 试试现在会提醒什么"和一行读数（现在几档、推不推手机）。
抽屉内容由本模块的 `settings(host, ctx)` 画，`renderSettings()` 是纯函数（离线可测）；
档位选项表仍然只有 `STEP_CHOICES` 一份。为什么这么搬：一页上可能有好几个功能都有设置，
齿轮 + 抽屉是这套应用统一的"细项放这里"入口（与课程辅助一致），卡片只做"一眼能看懂的概览"。

它随时告诉你**接下来什么时候会被叫**（每个任务的"下一次提醒"），也可以「试试现在会提醒什么」。
接口：`GET/POST /api/ddl` · `POST /api/ddl/check` · `POST /api/ddl/reset`（清掉"已提醒"记录，要显式确认）。
