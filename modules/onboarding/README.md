# 五步上手（onboarding）

平台的第一印象：**五步导览**（数据源 → 分析偏好 → 已有功能模块 → 新建功能 → UI 选择），
每一步都能跳过、随时能回来，进度记在 `prefs.onboarding_wizard` 里。

同一页右上角有 **用户模式 / 开发者模式**（`prefs.ui_mode`）：

- **用户模式**（默认）：只看到能用的东西；
- **开发者模式**：多出「能力清单 / 画一个功能 / 写一个功能 / 写一个模块 / 开发者指南」与命令行速查。

设计上刻意做到：**"已完成"是真实状态推出来的** —— 数据源配了几个、有没有声明式功能、外观换没换，
都是去问接口/本机状态；只有"挑功能"那一步没有机器可判的信号，所以那一颗勾是自觉勾，文案里也如实这么写。
