# 上课前检查（preclass-card）

挂在「今日」页的卡片，给"**上课前 N 分钟自动看一眼这门课的 Canvas**"一个看得见的地方。

- 上面列出**接下来 N 分钟内要上的课**，以及这节课"查过没有"；
- 下面四个设置：提前几分钟、启用、进通知、推手机（只发一句话）、以及"只看最近多少小时的材料"；
- 「试一次（演练）」= 只规划不打扰；「现在真查一次」= 真的查、有新东西才进通知。

背后的三块：`lib/preclass.mjs`（纯函数：算哪节课、折成 signal）、
`modules/preclass-check/`（功能：查 Canvas、决定要不要报）、
`lib/preclass-run.mjs`（调度：一节课只查一次、报过的不再报）。
