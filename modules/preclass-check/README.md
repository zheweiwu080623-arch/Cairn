# 上课前 Canvas 检查（preclass-check）

`kind: processor`。**在哪一刻跑**由调度器决定：某节课开始前 N 分钟（默认 30，可调）。

| 它做什么 | 说明 |
| --- | --- |
| 只查这一门课 | 文件 / 页面 / 公告 / 作业 / 小测，**只读 GET**；不碰其它课程，也不改任何东西 |
| 只报新东西 | 和"上次检查记下的指纹"比对；报过的不会再报 |
| 有新 → 通知 | 应用内通知（标题带课号与剩余分钟）；你勾了手机推送就再加一条 ≤60 字的短句 |
| 没有 → 安静 | 返回空数组；"没有新东西"是正确结果，不硬造通知 |
| 查不到 → 也不吵 | 没配 Canvas / 网络失败 / 这门课不在 Canvas 上：只留一行日志，不打扰你 |

设置（存在本机，可在「今日」页的卡片里改）：提前多少分钟、是否推手机、只看最近多少小时的材料。

边界：**不下载、不提交、不代做**；手机推送永远只发一句话（Bark 显示不了长文本）。
