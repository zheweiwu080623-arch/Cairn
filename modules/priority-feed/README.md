# 模块：重要信息（priority-feed）

挂在「今日」页顶部的可插拔模块。它做的事只有一件：
**按你的未来规划，把刚收集到的信息排出先后，并说明为什么。**

- 数据来自 `/api/priority`（逻辑在 `lib/priority.mjs`，纯函数，可单独测试）；
- 「我的未来规划」存在本机（`sync_state.plan_goals_json`），一行一条，随时改；
- 「让 agent 分析」优先用你配的 agent（Codex CLI / OpenAI 兼容 / Anthropic / Ollama）；
  **高峰时段不会调用模型**，先给规则版建议 —— 和整个平台的"非高峰才做费脑子的事"一致。

它**不改变**任何现有行为：不会自动把信息推成通知，也不会替你删东西。
