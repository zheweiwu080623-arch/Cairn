# 模块：我关心什么 · 信息筛选

这是平台上的**第一个可插拔模块**（`kind: gadget`，挂在「数据源」页里），
也是"加一个功能 = 加一个目录 + 注册一行"的第一个实例。

## 它做什么

按你的身份决定"外部进来的哪条信息值得打扰你"：

- **画像**：关注关键词 / 课程代码 / 关注发件人 / 屏蔽词 / 屏蔽发件人 / 两个阈值；
- **两条入口**：从应用已有数据**自动派生**（课表→课程代码、任务→目标词），或从**长期记忆文本一次性导入**；
- **行为学习**：同一个来源被你删 3 次 → 自动忽略；批准 2 次 → 自动优先（可一键清空）；
- **语义兜底**：规则拿不准的条目，**只在非高峰**交给 agent 判一次，理由写回条目。

## 它怎么接进平台

`module.json` 声明两件事：**数据面**（只读/只写什么）与**权限**（这里只需要 agent 调用）。
框架负责页面容器、主题、事件总线与错误兜底 —— 模块自己不写设置页、不管颜色、不碰别的表。

## 目录

| 文件 | 作用 |
| --- | --- |
| `module.json` | 描述符（契约见 `contracts/module.v1.schema.json`） |
| `view.js` | 前端入口：`renderCard()` 是纯函数（便于测试），`mount(el, ctx)` 负责挂载与交互 |

## 想照着写一个自己的模块？

复制这个目录，改 `module.json` 的 `id / name / kind / mount_into`，在 `view.js` 里导出 `mount(el, ctx)` 即可。
框架会通过 `/api/modules` 自动发现它，坏模块只会显示一行错误，不会拖垮整个应用。
