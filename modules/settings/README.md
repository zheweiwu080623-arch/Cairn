# 设置（settings）

把原来散在各处的东西收成一页（用户 2026-09-26 要求：「真做设置页，把数据源、外观、模式选择、功能调整几个部分放进去，
删掉数据源部分整合到设置中去，并将设置放在现在的风格位置，用一个齿轮图标，光标放在此处显示设置」）：

| 页签 | 里面是什么 | 原来的位置 |
| --- | --- | --- |
| 数据源 | 九种数据源 + 连接向导入口（**直接寄存原来的那一整块界面**，不重写） | 导航里的「数据源」页（已从导航移除） |
| 外观 | 主题（Persona 5 / Persona 3R）、应用显示名、壁纸入口说明 | 右上角的「🎨 风格」弹窗 |
| 模式 | 用户模式 / 开发者模式 | 之前只在五步向导里 |
| 功能 | 勾选要哪些功能模块 + ↑↓ 排序（保存即重排主页；没勾的不出现）；**有专属设置的功能**在这里只留一行"去那一页右上角 ⚙ 功能设置" | 之前只在五步向导里 |
| 本机 | 本机目录（壁纸 / 课程资料）、**本机工具**（pdftotext / pdftoppm，可选）、**计划导出格式**（md / json / ics / csv） | 2026-09-28 之前：只能改 `data\paths.json` 或环境变量 |
| 后台 | 服务在不在跑、开机自启开没开、一键开关自启 | 之前藏在数据源页底部 |
| 开发 | **开发者模式才出现**：写一个能力（单文件、不需要改内核）→ 保存注册 → 就地试跑 | 新 |

实现上刻意做的一件事：**数据源那一块是"寄存"而不是"重写"** —— 原来的 `#view-connectors` 整块
（连同它的事件绑定）被搬到设置页里，避免两套界面各写一遍以后又不一致。

两处 2026-09-27 的修正：

* 数据源页签里除了三块模块（Agent 接入 / 连接向导 / 每日摘要预览），**还把「课程资料自动同步」
  那一整块接了回来** —— 它一直是主程序画在 `#view-connectors` 里的，设置页改版后那一页没人够得着，
  于是"启用下载 / 连办公本 / 邮件桥发信 / 统一命名 / 每日清理"整块失联（和用户报过的
  "agent 接入没有了"是同一类问题）。现在容器不在就现建，主程序每次重画后叫
  `__cairnAdoptCourseSync` 再搬一次，保证搬过来的是最新那一帧。
* 功能页签不再假装"所有设置都在这儿"：每个功能自己的细项在自己的页面上改
  （见 `modules/course-assist-view/README.md`），设置页只负责"有哪些功能、什么顺序"。

## 2026-09-28：新增「本机」页签（P1「自定义补齐」）

缘由：有几样东西**每台机器都不一样**，之前只能开记事本改 `data\paths.json`，或者去改环境变量 ——
包括壁纸目录、课程资料目录，以及两个**可选**的 Poppler 小工具（pdftotext 取字、pdftoppm 转图）。
导出格式也只能是写死的 Markdown + JSON。

| 这一页做什么 | 走哪个接口 |
| --- | --- |
| 列 / 改本机目录与本机工具（含"现在用的是什么"） | `GET|POST /api/localdirs` |
| 弹系统选择框（选文件夹 / 选**文件**），只回填不落盘 | `POST /api/localdirs/pick` |
| 勾选导出格式 | `GET|POST /api/fn-settings`（功能 id = `plan_export`，字段 `formats`） |
| 直接下载某一种格式 | `GET /api/plan.md` / `/api/plan.json` / `/api/plan.ics` / `/api/plan.csv`（加 `?download=1` 就是下载） |

三条刻意的做法：

1. **本机工具是"可选的"，所以界面上不显示成故障** —— 它可能来自环境变量、来自这页配的值，
   也可能是应用自己找到的（例如跟着 Git for Windows 装的 poppler）。这页把这四种情况**分别写清**，
   空着不代表不能用；配错了也不会 silent 回退，会当场告诉你哪儿不对（不存在 / 是个文件夹 / PATH 里没有）。
2. **改完立刻生效**：写进 `paths.json` 之后由主程序把新值交给用它的模块（壁纸扫描 / 取字 / 转图），
   不需要重启（这条和壁纸目录两年前那次踩的坑是同一个教训）。
3. **导出格式的默认值不变**：没配过就是 Markdown + JSON —— 老装机升级上来行为完全一样；
   勾全去掉也算"回到默认"，而不是导出一堆空文件。
