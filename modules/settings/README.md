# 设置（settings）

把原来散在各处的东西收成一页（用户 2026-09-26 要求：「真做设置页，把数据源、外观、模式选择、功能调整几个部分放进去，
删掉数据源部分整合到设置中去，并将设置放在现在的风格位置，用一个齿轮图标，光标放在此处显示设置」）：

| 页签 | 里面是什么 | 原来的位置 |
| --- | --- | --- |
| 数据源 | 九种数据源 + 连接向导入口（**直接寄存原来的那一整块界面**，不重写） | 导航里的「数据源」页（已从导航移除） |
| 外观 | 主题（Persona 5 / Persona 3R）、应用显示名、壁纸入口说明 | 右上角的「🎨 风格」弹窗 |
| 模式 | 用户模式 / 开发者模式 | 之前只在五步向导里 |
| 功能 | 勾选要哪些功能模块 + ↑↓ 排序（保存即重排主页；没勾的不出现）；**有专属设置的功能**在这里只留一行"去那一页右上角 ⚙ 功能设置" | 之前只在五步向导里 |
| 后台 | 服务在不在跑、开机自启开没开、一键开关自启 | 之前藏在数据源页底部 |
| 开发 | **开发者模式才出现**：写一个能力（单文件、不需要改内核）→ 保存注册 → 就地试跑 | 新 |

实现上刻意做的一件事：**数据源那一块是"寄存"而不是"重写"** —— 原来的 `#view-connectors` 整块
（连同它的事件绑定）被搬到设置页里，避免两套界面各写一遍以后又不一致。

两处 2026-09-27 的修正：

* 数据源页签里除了三块模块（Agent 接入 / 连接向导 / 每日摘要预览），**还把「课程资料自动同步」
  那一整块接了回来** —— 它一直是主程序画在 `#view-connectors` 里的，设置页改版后那一页没人够得着，
  于是"启用下载 / 连办公本 / 邮件桥发信 / 统一命名 / 每日清理"整块失联（和用户报过的
  "agent 接入没有了"是同一类问题）。现在容器不在就现建，主程序每次重画后叫
  `__cairnAdoptCourseSync` 再搬一次，保证搬过来的是最新那一帧。
* 功能页签不再假装"所有设置都在这儿"：每个功能自己的细项在自己的页面上改
  （见 `modules/course-assist-view/README.md`），设置页只负责"有哪些功能、什么顺序"。
