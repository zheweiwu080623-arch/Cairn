# 模块：日报 / 晚报

挂在「今日」页（`kind: gadget`，`mount_into: today`），和「重要信息」是邻居。

**它解决什么**：`重要信息`卡片是"一长串排好序的信息"，适合有空时翻；
日报/晚报是**一眼看完的那三条**——早报看今天要准备什么，晚报看今天做完没有、明天先做什么。

- 内容来自 `GET /api/digest`（服务端 `lib/digest.mjs` 生成）；
- 排序直接复用 `GET /api/priority` 的那套引擎，所以"哪条重要"全项目只有一个定义；
- 「推到手机」走已有的 Bark 通道（`POST /api/digest/push`），**只有你点才会发**；
- 「让 agent 写建议」在非高峰调你自己配的模型（`POST /api/digest/advice`），
  高峰或失败自动回落规则版，并把原因说成人话。

它**不改变**任何现有推送：定时邮件、日常通知、Canvas 巡检都不受影响。
