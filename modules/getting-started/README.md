# 模块：从这里开始（getting-started）

挂在「今日」页最上面（`order: 0`），是**新用户第一眼看到的东西**。

四步（都可跳过）：

1. **给它起个名字** —— 写进 `<数据目录>/brand.json`（`data/` 不进仓库，所以名字是本机的）；
2. **连一个数据源** —— 跳到「数据源」页；最省事的是 RSS / 日历订阅（一个网址就行）；
3. **接上你自己的模型（可选）** —— 不接也能用；
4. **看一遍《它是怎么运作的》** —— 看完点"我看过了"。

两条设计原则：

- **勾是真的**：前两步的完成状态由服务端从**真实状态**推出来（`lib/onboarding.mjs`），
  不是"点过按钮就算完成"；
- **能收起来**：点「不再显示」写进本机偏好，之后不会再出现。

接口：`GET /api/prefs`（含 `brand` 与 `onboarding.steps/summary`）、`POST /api/prefs`。
